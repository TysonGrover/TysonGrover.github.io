Project: Drop Shock Testing Tower (In-Progress)

Senior Capstone Project for RAM Aviation, Space & Defense. Designed and built a drop‑shock test system capable of accelerating components into a controlled impact surface to simulate real‑world shock events such as aircraft takeoff and landing.

Goals
  • Deliver 400 G half-sine 5 ms pulse to solenoid valve
  • Tower height constrained to less than 10 feet
  • Prevent secondary shock events on test specimen
  • Enable variable drop height adjustment
  • Complete within $14,000 budget
  • 9-month project timeline
  • Implement comprehensive safety precautions

Project: Robotics Control System

Developed an autonomous navigation system for mobile robots using sensor fusion and machine learning algorithms to enable precise path planning and obstacle avoidance.

Step 1: Research
Analyzed existing navigation algorithms and identified key requirements for autonomous movement.
Step 2: Design
Created system architecture combining LIDAR, cameras, and IMU sensors for comprehensive environment mapping.
Step 3: Implementation
Implemented ROS-based control system with real-time sensor data processing.
Step 4: Testing
Validated system performance in various indoor and outdoor environments.
